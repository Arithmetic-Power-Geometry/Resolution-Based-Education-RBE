# Framework Crosswalk

RBE is designed as a conservative extension that can be mapped to established outcome-based and accreditation structures.

| Existing layer | RBE software object |
|---|---|
| Mission / societal needs | programme metadata |
| PEOs | programme objectives |
| POs / PSOs / graduate attributes | programme capability map |
| COs | RCOs with capability, environment, perturbation and decision semantics |
| Teaching-learning | CCVRT-aligned learning-plan metadata |
| Assessment | performance evidence + evidence state K0 |
| Attainment | PAR / RR / RAR / UAR / RNR / MRB |
| Continuous improvement | audit findings and closure records |
| QA / governance | policy, moderation, reliability, fairness, provenance and appeal fields |

The crosswalk does not claim endorsement by any external accreditation or regulatory body.
