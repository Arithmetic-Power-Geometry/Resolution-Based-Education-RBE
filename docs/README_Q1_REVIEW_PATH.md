# Q1 Review Path

The repository is organized so that the scientific claim can be inspected before implementation details.

**Problem → formal gate → conservative stop → CARG → resolving evidence → finite state → metrics → reproducibility → validation boundary.**

For a rapid review: read the top of `README.md`, run the Streamlit Reviewer Demo, inspect `docs/NOVELTY_MAP.md`, then run the scientific-invariant and mechanism tests. The repository deliberately does not treat passing software tests as evidence that RBE improves education.
