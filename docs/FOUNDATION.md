# RBE Theoretical Foundation

The reference implementation is linked to the foundation paper:

Mohammad Amir Khusru Akhtar (2026), *Beyond Outcome Attainment: Resolution-Based Education and the Certification–Assessment Resolution Gap in the Generative-AI Era*.

DOI: `10.5281/zenodo.22797079`

The software treats the foundation as the source for the CARG formulation, certification-resolution necessity condition, conservative evidence reuse, resolution-restoring policy distinction and resolved-attainment mathematics. Repository-level architecture, workflow, implementation and reproducibility artifacts operationalize those objects rather than claiming them again as independent software novelty.
