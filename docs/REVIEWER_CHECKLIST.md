# Reviewer Reproducibility Checklist

- [ ] The repository states the scientific question before installation details.
- [ ] Existing OBE evidence is preserved as the initial evidence state.
- [ ] Performance attainment and certification resolution are reported separately.
- [ ] The Resolution Gate condition is stated formally and in plain language.
- [ ] Resolution-adequate evidence can terminate with zero added burden.
- [ ] Operational unresolved status is not automatically mislabeled as CARG.
- [ ] A one-step informative probe is not mislabeled as a complete MRRP.
- [ ] Positive resolution is separated from resolved-negative status.
- [ ] AR/AU/RN/NA/Deferred states remain explicit.
- [ ] PAR/RR/RAR/UAR/RNR/MRB remain separately reportable.
- [ ] Mechanism tests are not described as educational-effectiveness evidence.
- [ ] Prior methodological ancestors are explicitly acknowledged.
- [ ] Foundation DOI is linked in repository citation metadata.
- [ ] Software, calculation-reproduction and educational validation are separated.
- [ ] High-stakes adoption claims require prospective comparative evidence.
