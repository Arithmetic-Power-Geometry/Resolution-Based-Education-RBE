# Final reviewer-oriented flow

`Existing OBE evidence → performance result → Resolution Gate → STOP if adequate / CARG if inadequate → MRRP or adaptive resolving evidence → re-evaluate → AR/AU/RN/Deferred → PAR/RR/RAR/UAR/RNR/MRB → programme evidence / passport / ledger / audit / improvement.`

The software preserves original performance evidence and keeps certification-resolution status explicit. The repository distinguishes mechanism/software evidence from prospective educational-effectiveness evidence.
