## Gate condition

`w_i ~_A w_j  =>  g(w_i) = g(w_j)`

All learner possibilities that remain observationally indistinguishable under the available assessment evidence must require the same certification decision.

## Stop rule

If the condition is already satisfied at K0, stop. RBE adds no evidence merely because the framework exists.

## Failure rule

If assessment-equivalent possibilities require different certification decisions, CARG is present. Additional evidence should target the unresolved distinction rather than automatically increase assessment volume.

## Finite rule

If no admissible resolution-restoring policy exists within the declared burden/procedural boundary, retain an unresolved/Deferred state. Do not manufacture certainty.
