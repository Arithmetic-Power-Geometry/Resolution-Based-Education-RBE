# Validation Layers

RBE deliberately separates three kinds of evidence.

## 1. Software validation

Question: does the implementation execute the declared rules consistently?

Evidence: unit tests, scientific-invariant tests, deterministic examples, CI and regression checks.

## 2. Calculation / reproduction validation

Question: does the software reproduce declared workbook calculations and saved mechanism examples within stated tolerances?

Evidence: workbook import/recomputation, generated artifacts, fixed seeds and saved outputs.

## 3. Educational validation

Question: does RBE improve decision quality, evidence efficiency, fairness, reliability or downstream capability inference compared with strong alternatives?

Evidence required: prospective comparative studies on the same capability claims, with strong OBE/evidence-rich, authentic/fixed-verification and programmatic/adaptive comparators where appropriate.

Software correctness and calculation reproduction do not establish Layer 3. Claims of educational superiority should report risk/error, coverage, burden, reliability, fairness/subgroup effects and relevant capability-transfer outcomes.
