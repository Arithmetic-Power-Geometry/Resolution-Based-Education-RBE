# RBE Novelty and Prior-Concept Boundary

This document is a claim-control map for reviewers, contributors and future manuscripts. It distinguishes established methodological ancestors from the specific objects operationalized by RBE.

| Object / approach | Status in RBE | Interpretation |
|---|---|---|
| Outcome-based education | established foundation | RBE preserves its outcome/attainment evidence and treats it as K0 |
| Authentic assessment | established | possible evidence source |
| Oral defence / verification | established | possible probe |
| Programmatic assessment | established | evidence-rich comparator |
| Adaptive/sequential testing | established | methodological ancestor for evidence acquisition |
| Bayesian updating | established | optional probabilistic mechanism |
| Information gain | established | optional probe-selection quantity |
| Equivalence relations / partitions | established mathematics | formal language used by the theory |
| Reject/abstain decisions | established | methodological neighbor to Deferred states |
| CARG | RBE foundation object | decision-relative mismatch: assessment-equivalent possibilities require different certification decisions |
| Certification Resolution Necessity | RBE foundation theorem | evidence obtainable under a protocol cannot universally support distinctions that the protocol cannot observe |
| Outcome–Resolution Separation | RBE foundation proposition | performance attainment does not logically imply certification resolution |
| Conservative Extension / Evidence Reuse | RBE foundation proposition | resolution-adequate existing evidence requires zero additional RBE burden |
| RCO=(C,E,P,D) | RBE operating object | capability claim plus relevant environments, admissible perturbations and certification distinction |
| Resolution Gate | RBE operating mechanism | asks whether current evidence already resolves the declared decision distinction |
| MRRP | RBE operating mechanism | complete resolution-restoring probe/policy selected under burden and validity constraints |
| AR/AU/RN/NA/Deferred | RBE reporting architecture | separates performance status from certification-resolution status |
| PAR/RR/RAR/UAR/RNR/MRB | RBE reporting layer | exposes performance, resolution and burden separately |

## Claim discipline

The repository does not use the existence of software as evidence of educational effectiveness. It does not describe ordinary oral defence, adaptive testing, information gain, Bayesian updating, equivalence relations, authentic assessment or programmatic assessment as RBE inventions. Comparative superiority must be supported by prospective evidence against strong baselines.
