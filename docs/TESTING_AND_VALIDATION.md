# Testing and Validation Plan

## Software verification
- Unit tests for positive resolution, resolved-negative states and burden-cap states.
- Unit tests for probe admissibility and minimum-burden selection.
- Unit tests for course and programme attainment mathematics.
- End-to-end Theory of Computation fixture.

## Educational validation before high-stakes use
1. Content/construct review by domain experts, educationists, psychometricians, accessibility experts and students.
2. Shadow mode without changing official grades.
3. Low-stakes pilot and assessor calibration.
4. Controlled comparison against current OBE and strong enhanced/evidence-rich baselines.
5. Limited certification pilot with moderation and appeal.
6. Programme-level scale only after validity, fairness and reliability evidence.
7. External review and replication.

## Falsification principle
If RBE does not improve the relevant risk-coverage-burden trade-off, external-task validity, or other predeclared decision criteria over strong comparators, superiority is not demonstrated.
